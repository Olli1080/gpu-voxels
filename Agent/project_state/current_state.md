## The project
GPU-Voxels: C++20 library (originally FZI Karlsruhe, 2014; maintained as a fork by Oliver Zahn) for GPU voxel maps, lists and octrees with collision detection and distance maps, for robot planning. Currently **CUDA 12 + Thrust**, built with CMake ≥ 3.23 + vcpkg manifest on Windows/MSVC. Goal: **migrate to Vulkan** (user decision; API binding and details open — see [open_questions.md](open_questions.md)).
Architecture summary: [architecture/](../knowledge_base/architecture/summary.md).
